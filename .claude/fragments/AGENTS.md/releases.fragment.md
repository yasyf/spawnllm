**Releases.** Tagging `v*` triggers `.github/workflows/release.yml`, the single workflow that releases every language. It builds the wasm blob once and publishes it as a release asset, then fans out: the PyPI wheels and sdist via trusted publishing, the macOS platform wheel carrying the Swift sidecar, the `go/vX.Y.Z` alias tag, the crates.io publish, and the descriptor commit back to `main`. A final job cuts the GitHub release once every language artifact has landed. The version comes from the tag.
