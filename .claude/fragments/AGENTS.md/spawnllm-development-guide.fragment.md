# spawnllm Development Guide

Subshell + MLX LLM-calling backends (Claude/Codex CLI, local MLX) shared across tools. Published to PyPI as `spawnllm`; the CLI is `spawnllm`, run as `uvx spawnllm`.

## Repository Structure

```
spawnllm/
├── spawnllm/         # The Python package — thin host over the core: subprocess/HTTP I/O, MLX engine, Click CLI
│   └── _core/        # wasmtime glue + the gitignored wasm blob (built, never committed)
├── rust/             # Cargo workspace: spawnllm-core (the engine), spawnllm (crate), spawnllm-wasm, conformance-gen
├── go/               # Go module — wazero host over the same core
├── conformance/      # Committed golden vectors + wire schemas (generated by conformance-gen)
├── tests/            # Pytest suite (includes the vector replay through the wasm glue)
├── scripts/          # build_wasm.sh — fetches or builds the blob into go/internal/core/ and spawnllm/_core/
├── .github/          # GitHub Actions workflows
├── AGENTS.md         # This file — shared conventions
└── README.md         # Project overview
```

## Shared Core (spawnllm-core)

All drift-prone logic — argv planning, envelope resolution, strict-schema transforms, JSON extraction, retry policy, auth probes, isolation seeding — lives once in `rust/spawnllm-core`. Python and Go embed it as a wasm blob; the Rust crate links it natively. The blob is never committed: `task blob` (or `bash scripts/build_wasm.sh`) resolves it into both host trees — it downloads the source-hash-stamped asset from the release that first published it, and builds from source only on a miss (only that build path needs `rustup target add wasm32-wasip1`). A missing blob fails loudly (Go: compile error; Python: `FileNotFoundError` naming the script).

**Fix behavior core-first.** A behavior change edits the Rust core, regenerates the golden vectors (`cargo run -p conformance-gen -- --write`), and lands both in one commit — every host inherits the change through its replay test. Never hand-edit files under `conformance/`, and never reintroduce portable logic into a host.
